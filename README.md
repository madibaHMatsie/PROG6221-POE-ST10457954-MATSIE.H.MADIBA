# CYBERBOT
 CYBERSECURITY AWARENESS CHATBOT
It provides South African users with an engaging, voice-enabled cybersecurity education tool that remembers their preferences, detects their mood, and practical tips to keep them safe online.
 The project is a WPF GUI application with sentiment detection,memory,keyword recognition and random responses.
## Features
Voice greeting (Microsoft Zira – female)
- Task assistant with MySQL storage
-  Cybersecurity quiz (11 questions)
-  Activity log
- Sentiment detection
-  Memory (name + interest)
-  NLP simulation
